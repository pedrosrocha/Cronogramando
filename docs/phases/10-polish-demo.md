# Phase 10 — Test Automation, Polish & Demo

## Goal
Close the loop as a QA engineer: automate the API and the app at the right
levels, run the suite in CI, then polish for a credible demo.

## Sub-phases
| Sub-phase | Question it answers |
|---|---|
| [10a — API + mobile test automation](10a-test-automation.md) | How do I automate the backend contract, the Flutter UI and real device flows? |
| [10b — Polish, device QA & demo](10b-polish-demo.md) | How do I prove quality and present the project? |

## Exit criteria
- [ ] API contract + backend unit tests + Flutter unit/widget tests run in CI
- [ ] At least one critical flow runs as an integration test on an Android
      emulator
- [ ] The live API smoke test from Phase 08b is scheduled and reports failures
- [ ] Test strategy, device matrix and flaky-test policy are documented
- [ ] A real bug was found through automation and fixed
- [ ] The demo runs end to end and the README explains how to run and test it
